# ECHO//STORM

A browser prototype for a new music-survival genre.

> You don't fight the song. You survive it.

## Current base

- Medium-size browser battlefield rather than a huge open world.
- Upload a local audio file and use it as the storm soundtrack.
- Web Audio analysis drives storm intensity.
- Music intensity changes monster spawning and portals.
- Player can run, sprint and dash instead of being forced to fight.
- Music creatures use dark bodies, neon echoes and radial attacks.
- Worlds/styles rotate during a run: anime, cartoon, paper, manga, glitch, realistic, void and pixel.
- Each wave represents another phase of the song/world.
- No external game engine required.

## Run

Open `music-storm/index.html` in a modern browser. For local-file audio and browser security, a small local HTTP server is recommended.

This is intentionally a **base prototype**, not the finished game. Next systems should include reliable beat/onset detection, world generation, distinct monster behaviors, safe zones, song chapters, procedural portals, character animation, mobile controls, and a proper run/score loop.

## Copyright

The prototype does not ship commercial songs. Players provide their own audio files. Any distributed music should be properly licensed.
