# Hayate Run (疾風)

A single-file browser runner game in the style of an anime opening. Pick a song and a runner, then dodge buildings, trees and people and jump over holes.

- Original synth tracks, including a slow-motion crescendo and a hype drop
- 8 render styles: Anime, Cartoon, Paper, Manga, Comic, 3D, Flat 2D, Realistic
- Optional: load your own audio file and set its BPM

## Run
Open `index.html` in a browser, or enable GitHub Pages (Settings > Pages > main / root).

## Controls
Arrow keys or A/D change lane, Up/Space jumps. On touch: swipe left/right, swipe up or tap to jump.
