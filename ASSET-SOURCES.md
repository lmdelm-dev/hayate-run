# Hayate Run — character asset provenance

The game must not ship ripped anime/game characters. The playable cast in `characters.js` is original/procedural and only uses the CC0 resources below as optional references or future source material.

## CC0 anime-style sources

- OpenGameArt — Anime Collection: https://opengameart.org/content/anime-collection
- OpenGameArt — Anime Girl / Michona: https://opengameart.org/content/anime-girl
- OpenGameArt — Anime Style Walkabouts: https://opengameart.org/content/anime-style-walkabouts
- SpriteCook Free Game Assets: https://github.com/SpriteCook/spritecook-free-game-assets
- RGS Dev — Free CC0 Modular Animated Vector Characters: https://rgsdev.itch.io/free-cc0-modular-animated-vector-characters-2d

All listed sources were checked for CC0/public-domain-equivalent licensing at the time of implementation. If a source is imported later, preserve its original license/author metadata and update this file.

## Character design rule

Do not use recognizable copyrighted anime characters, logos, screenshots, or ripped sprites. Character names, silhouettes, colors, clothing combinations, accessories, animations, and story roles should be original.
